# Ibraheem Catovic · Unofficial academic portfolio concept

A complete static Astro + TypeScript website by Academic Web Studio. Warm paper, forest green, self-hosted Newsreader and DM Sans, an original vector illustration, responsive editorial layouts, and reusable academic content components.

**Unofficial design concept. Not affiliated with or endorsed by Professor Catovic or NYU. Published with the founders’ approval as a public review demo. No professor outreach has been performed.**

## Online review demo

https://academic-web-studio-catovic-demo.netlify.app/

Source: https://github.com/juhdonn/catovic-academic-concept (private). Netlify Free builds and deploys `main` automatically. The website is public; the GitHub repository remains private. See `DEPLOYMENT.md` for the live deployment record and update instructions.

## Run locally

Requires Node.js 22.23.4 or newer (Node 24 used here).

```sh
npm ci
npm run build
npm run preview -- --port 4321
```

Open http://127.0.0.1:4321. The preview binds to loopback only. The current preview uses this address. In current Astro, `npm run preview -- stop` stops its preview daemon; `npm run preview -- status` reports its status.

For editing with live reload:

```sh
npm run dev
```

## Pages and features

- Overview: academic introduction, appointment, original editorial illustration, featured research, teaching, and contact.
- Research: all ten original entries; subject filters, title search, result announcements, and a publication overview.
- Teaching: all seven courses, with all 23 original syllabus links.
- About: verified education, professional history, research interests, and concept disclosure.
- CV: direct access to both original CV files, with an explanation of the versions.
- Contact: original professional email, working email copy, address as printed in the CV, and academic links.
- Sources: evidence and uncertainties; custom 404 page.

Navigation and reading work without JavaScript. Filters, the mobile menu, and email copy use small progressive scripts. No React runtime, CMS, database, analytics, third-party font request, or paid service is required. No photograph is fabricated.

## Reuse for future clients

1. Replace `src/data/profile.ts` with a verified profile, education, experience, publications, and courses. Keep uncertainty notes alongside the relevant records.
2. Update the introduction and about copy in `src/pages/index.astro` and `src/pages/about.astro`. Copy is intentionally bespoke, not an autogenerated biography.
3. Set design tokens in `src/styles/global.css`: paper, ink, green, sage, serif, and sans families.
4. Reuse `Layout.astro`, `PageHead.astro`, and `PaperRow.astro`. `Paper` is typed and supports publication status, venue, coauthors, an overview, and a link-issue note.
5. Update source documentation, concept labels, footer, favicon, and SEO metadata for the new client.
6. Re-run browser QA and source verification. Do not reuse this professor’s content for another client.

## Source structure

```
src/data/profile.ts        Verified academic records and original links
src/components/           Shared paper row and page introduction
src/layouts/Layout.astro  Navigation, metadata, fonts, footer, mobile menu
src/pages/                Eight generated HTML pages
src/styles/global.css     Design tokens, layouts, responsive styles, reduced motion
public/                   Favicon and demo robots exclusion
docs/                     Research, QA, deployment, screenshots
scripts/verify-build.py   Internal-link and document-structure checks
```
